DOCUMENTACIÓ DE PROVA - CtrlPersistenciaDriver
===============================================

OBJECTE DE LA PROVA
-------------------
Prova del controlador de persistència (guardar/carregar dades).

Casos d'ús provats:
- Guardar enquestes en fitxers JSON
- Carregar enquestes des de fitxers JSON
- Guardar usuaris
- Carregar usuaris
- Exportar dades completes del sistema
- Importar dades completes del sistema

Classes provades:
- CtrlPersistencia: serialització i deserialització

ELEMENTS INTEGRATS
------------------
Totes les classes de domini:
- Usuari, Enquesta, Pregunta, Resposta, Opcio

Llibreries externes:
- GSON 2.8.9: serialització JSON
- JSON 20231013: manipulació JSON

FITXERS DE DADES NECESSARIS
----------------------------
Generats pel driver:
- enquestes.json: array d'objectes Enquesta
- usuaris.json: array d'objectes Usuari
- respostes.json: array d'objectes Resposta
- sistema_complet.json: estat complet del sistema

VALORS ESTUDIATS (Caixa Blanca i Negra)
----------------------------------------
1. Serialització correcta:
   - Enquesta amb preguntes → JSON
   - Usuari amb enquestes → JSON
   - Resposta amb referències → JSON

2. Deserialització:
   - JSON vàlid → objectes Java
   - JSON invàlid → gestió d'errors
   - Fitxer inexistent → array buit o error

3. Persistència completa:
   - Guardar estat complet
   - Carregar i restaurar estat
   - Integritat referencial (IDs)

4. Casos límit:
   - Fitxers buits
   - JSON malformat
   - Fitxer sense permisos
   - Ruta inexistent

EFECTES ESTUDIATS
-----------------
- Lectura/escriptura de fitxers
- Gestió d'errors d'I/O
- Format JSON llegible
- Preservació de referències entre objectes

OPERATIVA
---------
Execució:
```
cd FONTS
gradlew.bat runCtrlPersistenciaDriver
```

Opcions del menú:
1. Guardar enquestes
2. Carregar enquestes
3. Guardar usuaris
4. Carregar usuaris
5. Exportar sistema complet
6. Importar sistema complet
7. Llistar fitxers guardats
0. Sortir

Flux típic d'exportació/importació:
1. Crear dades (usuaris, enquestes, respostes)
2. Exportar sistema complet
3. Sortir del programa
4. Executar de nou
5. Importar sistema complet
6. Verificar que les dades s'han restaurat

Notes:
- Els fitxers es guarden al directori actual
- Format JSON human-readable
- Validació d'integritat en càrrega
