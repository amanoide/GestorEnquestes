joc de proves del Driver CtrlResposta

---- JOC DE PROVA CAIXA GRISA ----
Aquest joc de proves esta fet amb valors de la caixa grisa, es testeja tot el possible

- Objecte de la prova:
    Amb aquest joc de proves es proven els seguents casos d'us:
      0: Tancar driver
      1: Contestar enquesta
      2: Modifica resposta
      3: Esborrar resposta
      4: Importar resposta
      5: Consulta de respostes per enquesta

    - Es comproven tant els fluxos correctes (happy paths) com multiples errors (duplicats, credencials incorrectes, parametres invalids).

- Altres elements integrats a la prova:
    - CtrlDomini i CtrlPersistencia son reutilitzats per la gestio d'enquestes i respostes.
    - Es reutilitzen els drivers/estructures de Pregunta/Opcio per convertir la resposta textual a les representacions esperades.

- Fitxers de dades necessaris:
    - Codi del driver Resposta
    - run_tests.sh / run_tests.bat (windows) per executar el joc de proves
    - `DOCS/exemple_resposta_clustering.json` — fitxer de mostra amb respostes en format JSON esperat pel metode d'import.
    - `DOCS/exemple_enquesta_clustering.json` — fitxer de mostra de l'enquesta requerida per l'import de resposta en format JSON.
    - Si no existeix, el script prova tambe la ruta no valida per validar errors d'import.

- Valors estudiats:
    - run_tests.sh o .bat (windows)
    - La missio d'aquest arxiu es proporcionar valors per veure el bon funcionament del programa passant per totes les funcions

    - Comprova, en aquest ordre:
        - Crea usuaris (alice i bob)
            -Missio: per a que contestin la enquesta creada com a mock.
        ...
        ...
        - Bob contesta enquesta 1 totes les preguntes (text, numerica, opcions).
            -Missio: Comprobar el bon funcionament de la funcionalitat contestar enquesta, ha d'haver contestat sense problemes
        
        - Bob contesta enquesta 1 totes les preguntes amb respostes diferents(error esperat - ya contestada)
            -Missio: Comprobar que no es pot contestar dos cops amb un mateix usuari la mateixa enquesta
        
        - Intent de contestar enquesta no existent (error esperat)
            -Missio: Comprobar que no es possible contestar una enquesta no existent, demanara un valor valid d'enquesta
        
        - Modificar una resposta de Bob (cambiar valor)
            -Missio: Comprobar el bon funcionament de la funcionalitat modificar resposta.
        
        - Intent de modificar resposta que no existeix (error esperat)
            -Missio. Comprobar que no es pot modificar una resposta no existent, demanara introduir un valor valid.
        
        - Esborrar una resposta de bob
            -Missio: Comprobar que funciona correctament esborrar resposta
        
        - Consultar respostes de enquesta 1 (veure estat final)
            -Missio: Llista les enquestes per poder comprobar que les anteriors funcionalitats s'han implementat correctament 
        
        - Consultar respostes de enquesta no existent (error esperat)
            -Missio: Comprobar que no es pot llistar un enquesta si no existeix, demanara un valor valid d'enquesta.
        
        - Importar respostes desde fitxer a enquesta no existent(si existe DOCS/exemple_resposta_clustering.json)
            -Missio: Comprobar que no es pot importar un fitxer si no existeix l'enquesta a la que respon
        
        - Intent de importar desde ruta no valida (error esperat)
            -Missio: Comprobar que no es pot importar un fitxer si no existeix
        
        - Importar enquesta
            -Missio: Importar una enquesta per a poder importar la seva resposta.
        
        - Importar respostes desde fitxer a enquesta existent (si existe DOCS/exemple_resposta_clustering.json)
            -Missio: Comprobar el correcte funcionament de la funcionalitat importar
        
        - Llistar respostes importades
            -Missio: Comprobar que s'han executat correctament les funcionalitats anteriors



- Efectes estudiats:
    - Comprovacio que les respostes s'emmagatzemen correctament amb la clau esperada i que les consultes retornen les estructures esperades.
    - Verificacio dels permisos (nomes l'autor pot modificar/esborrar la seva resposta) i missatges d'error coherents.
    - Missatges d'error i d'exit a la consola.


- Operativa (us rapid):
    - Script d'execucio: `ENTREGA/EXE/CtrlResposta/run_tests.sh`.
    - Execucio:
      cd ENTREGA/EXE/CtrlResposta
      chmod +x run_tests.sh
      ./run_tests.sh
    - El driver necessita que hi hagi una enquesta mock amb preguntes (ja la crea a init()). El script creara usuaris mock i provara tot el flux d'entrades i imports.
    
    - El script crida la task Gradle `runCtrlUsuariDriver` des del directori `ENTREGA/FONTS` per llancar el driver automaticament. 
    - La sortida mostra el pas a pas de les proves a l'arxiu PROVA.txt.

     En cas que no funcioni, executa per solucionar els salts de línia: sed -i 's/\r$//' run_tests.sh


-Si desitjes executar el driver individualment:
    cd ENTREGA/FONTS
    ./gradlew runCtrlRespostaDriver

Notes:
- Revisa `PROVA.txt` a la carpeta per veure la sortida capturada de l'execucio.
- Per provar amb un fitxer real d'importacio, col·loca el JSON a `ENTREGA/DOCS/` o passa la ruta correcta quan el script demani el fitxer.
