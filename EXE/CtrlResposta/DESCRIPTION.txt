Objecte de la prova:
- Provar la funcionalitat de registre, modificació, esborrat i consulta de respostes a enquestes.
- Casos d'ús: contestar enquesta (per diferents tipus de pregunta), modificar resposta, esborrar resposta, importar respostes desde JSON i consultar les respostes existents.
- Classes provades: CtrlResposta (via CtrlDomini), Resposta, Pregunta (interpretació de formats de resposta), CtrlEnquesta (per registre i existència d'enquestes).

Altres elements integrats a la prova:
- CtrlDomini i CtrlPersistencia són reutilitzats per la gestió d'enquestes i respostes.
- Es reutilitzen els drivers/estructures de Pregunta/Opcio per convertir la resposta textual a les representacions esperades.

Fitxers de dades necessaris:
- `DOCS/exemple_resposta_clustering.json` (si existeix) — fitxer de mostra amb respostes en format JSON esperat pel mètode d'import.
- Si no existeix, el script prova també la ruta no vàlida per validar errors d'import.

Valors estudiats:
- Respostes vàlides: text lliure, numèriques dins dels límits definits, selecció d'opcions per qualitatives (text o ids), seleccions múltiples (ids separats per coma).
- Respostes invàlides: respostes fora de rang numèric, text buit quan no permès, identificadors d'opcions inexistents.
- Estratègia: provar combinacions d'entrades per a cada tipus de pregunta i casos límit (valor mínim/màxim, no selecció, múltiples amb duplicats).

Efectes estudiats:
- Comprovació que les respostes s'emmagatzemen correctament amb la clau esperada i que les consultes retornen les estructures esperades.
- Verificació dels permisos (només l'autor pot modificar/esborrar la seva resposta) i missatges d'error coherents.

Operativa (ús ràpid):
- Script d'execució: `ENTREGA/EXE/CtrlResposta/run_tests.sh`.
- Execució:
  cd ENTREGA/EXE/CtrlResposta
  chmod +x run_tests.sh
  ./run_tests.sh
- El driver necessita que hi hagi una enquesta mock amb preguntes (ja la crea a init()). El script crearà usuaris mock i provarà tot el flux d'entrades i imports.

Notes:
- Revisa `PROVA.txt` a la carpeta per veure una execució de mostra amb la sortida capturada.
- Per provar amb un fitxer real d'importació, col·loca el JSON a `ENTREGA/DOCS/` o passa la ruta correcta quan el script demani el fitxer.
