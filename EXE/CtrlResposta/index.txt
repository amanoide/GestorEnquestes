DIRECTORI: ENTREGA/EXE/CtrlResposta
====================================

Descripcio: Scripts i recursos per provar el controlador de respostes

Contingut:
----------

DESCRIPTION.txt
  Descripcio detallada de l'objecte de la prova, valors i efectes estudiats.

PROVA.txt
  Script de prova automatitzada per CtrlRespostaDriver.
  Conte casos de prova extensius per testejar totes les funcionalitats
  del controlador de respostes d'enquestes.

run_tests.sh
  Script bash per executar les proves automaticament (Linux/Mac).

run_tests.bat
  Script batch per executar les proves automaticament (Windows).

================================================================================
OBJECTE DE LA PROVA
================================================================================

- Provar la funcionalitat de contestar, modificacio, esborrat i importacio
  de respostes a enquestes.
- Casos d'us: contestar enquesta (per diferents tipus de pregunta), modificar
  resposta, esborrar resposta, importar respostes desde JSON.
- Classes provades: CtrlResposta (via CtrlDomini), Resposta, Pregunta
  (interpretacio de formats de resposta), CtrlEnquesta (per registre i
  existencia d'enquestes).

Altres elements integrats a la prova:
-------------------------------------
- CtrlDomini i CtrlPersistencia son reutilitzats per la gestio d'enquestes
  i respostes.
- Es reutilitzen els drivers/estructures de Pregunta/Opcio per convertir la
  resposta textual a les representacions esperades.

Fitxers de dades necessaris:
----------------------------
- DOCS/exemple_resposta_clustering.json - fitxer de mostra amb respostes en
  format JSON esperat pel metode d'import.
- DOCS/exemple_enquesta_clustering.json - fitxer de mostra de l'enquesta
  requerida per l'import de resposta en format JSON.
- Si no existeix, el script prova tambe la ruta no valida per validar errors
  d'import.

================================================================================
VALORS ESTUDIATS
================================================================================

- Respostes valides: text lliure, numeriques dins dels limits definits,
  seleccio d'opcions per qualitatives (text o ids), seleccions multiples
  (ids separats per coma).
- Respostes invalides: respostes fora de rang numeric, text buit quan no
  permes, identificadors d'opcions inexistents.
- Estrategia: provar combinacions d'entrades per a cada tipus de pregunta i
  casos limit (valor minim/maxim, no seleccio, multiples amb duplicats).

================================================================================
EFECTES ESTUDIATS
================================================================================

- Comprovacio que les respostes s'emmagatzemen correctament amb la clau
  esperada i que les consultes retornen les estructures esperades.
- Verificacio dels permisos (nomes l'autor pot modificar/esborrar la seva
  resposta) i missatges d'error coherents.

================================================================================
CASOS DE PROVA IMPLEMENTATS (segons PROVA.txt)
================================================================================

SETUP INICIAL:
- Creacio d'usuari i enquesta mock automatica

USUARIS I LOGIN (casos 1-6):
1-2. Crear usuaris mock (alice, bob)
3-4. Login i logout amb usuaris valids
5-6. Errors de login (credencials incorrectes, usuari inexistent)

CONTESTAR ENQUESTA (casos 7-11):
7. Alice contesta enquesta completa
8. Bob contesta enquesta amb respostes diferents
9. Intento de recontestar (modificar enlloc de crear nova)
10. Error: enquesta inexistent
11. Error: resposta buida a pregunta obligatoria

MODIFICAR RESPOSTA (casos 12-15):
12. Modificar resposta d'alice
13. Error: modificar resposta d'altre usuari
14. Error: resposta inexistent
15. Error: enquesta inexistent

ESBORRAR RESPOSTA (casos 16-19):
16. Esborrar resposta de bob
17. Error: resposta inexistent
18. Error: esborrar resposta d'altre usuari
19. Error: enquesta inexistent

CONSULTAR RESPOSTES (casos 20-21):
20. Consultar totes les respostes d'una enquesta
21. Error: enquesta inexistent

IMPORTAR RESPOSTES (casos 22-23):
22. Importar desde fitxer JSON
23. Error: ruta invalida

================================================================================
OPERATIVA (US RAPID)
================================================================================

Script d'execucio:
  Linux/Mac: ENTREGA/EXE/CtrlResposta/run_tests.sh
  Windows: ENTREGA\EXE\CtrlResposta\run_tests.bat

Execucio en Linux/Mac:
  cd ENTREGA/EXE/CtrlResposta
  chmod +x run_tests.sh
  ./run_tests.sh

Execucio en Windows:
  cd ENTREGA\EXE\CtrlResposta
  run_tests.bat

El driver necessita que hi hagi una enquesta mock amb preguntes (ja la crea
a init()). El script creara usuaris mock i provara tot el flux d'entrades
i imports.

Si desitges executar el driver individualment:
  cd ENTREGA/FONTS
  ./gradlew runCtrlRespostaDriver

================================================================================
NOTES
================================================================================

- Revisa PROVA.txt a la carpeta per veure una execucio de mostra amb la
  sortida capturada.
- Per provar amb un fitxer real d'importacio, col·loca el JSON a ENTREGA/DOCS/
  o passa la ruta correcta quan el script demani el fitxer.
- El script PROVA.txt esta dissenyat per executar-se automaticament.
- Crea usuaris mock amb password 'pwd1' per defecte.
- Valida permisos (un usuari nomes pot modificar les seves respostes).
- Suporta tots els tipus de preguntes del sistema.
- Les opcions es mostren amb IDs reals per facilitar la seleccio.
- La validacio accepta tant IDs numerics com text per opcions.
