DOCUMENTACIÓ DE PROVA - CtrlEnquestaDriver
===========================================

OBJECTE DE LA PROVA
-------------------
Prova del controlador d'enquestes.

Casos d'ús provats:
- Crear enquestes noves
- Modificar enquestes existents (títol, descripció)
- Eliminar enquestes
- Consultar enquestes
- Gestionar preguntes associades a enquestes

Classes provades:
- CtrlEnquesta: lògica de gestió d'enquestes
- Enquesta: classe de domini

ELEMENTS INTEGRATS
------------------
Classes reutilitzades:
- Usuari: creador de l'enquesta
- Pregunta: preguntes de l'enquesta
- CtrlPersistencia: guardar/carregar enquestes

FITXERS DE DADES NECESSARIS
----------------------------
Opcionals:
- enquestes.json: enquestes guardades prèviament

VALORS ESTUDIATS (Caixa Negra)
-------------------------------
1. IDs d'enquesta:
   - Vàlids: "E1", "ENQ001", "test_enquesta"
   - Duplicats: mateix ID dues vegades (error esperat)

2. Títols:
   - Cadenes normals: "Enquesta de satisfacció"
   - Buides: "" (error esperat)
   - Llargues: més de 100 caràcters

3. Descripcions:
   - Text normal, null, buides

4. Operacions:
   - Crear amb 0 preguntes
   - Crear amb múltiples preguntes
   - Modificar enquesta amb respostes
   - Eliminar enquesta amb respostes

EFECTES ESTUDIATS
-----------------
- Visualització de llista d'enquestes
- Selecció d'enquesta per modificar
- Missatges de confirmació/error

OPERATIVA
---------
Execució:
```
cd FONTS
gradlew.bat runCtrlEnquestaDriver
```

Opcions del menú:
1. Crear enquesta
2. Modificar enquesta
3. Eliminar enquesta
4. Llistar enquestes
5. Consultar detalls d'enquesta
0. Sortir
