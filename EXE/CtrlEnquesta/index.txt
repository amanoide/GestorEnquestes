DIRECTORI: ENTREGA/EXE/CtrlEnquesta
====================================

Descripcio: Scripts i recursos per provar el controlador d'enquestes

Contingut:
----------

DESCRIPTION.txt
  Descripcio detallada de l'objecte de la prova, valors i efectes estudiats.

PROVA.txt
  Script de prova automatitzada per CtrlEnquestaDriver.
  Nota: Aquest fitxer esta actualment buit.

run_tests.sh
  Script bash per executar les proves automaticament (Linux/Mac).

run_tests.bat
  Script batch per executar les proves automaticament (Windows).

================================================================================
OBJECTE DE LA PROVA
================================================================================

- Provar la gestio d'enquestes i preguntes: crear/modificar/esborrar enquestes,
  afegir/modificar/esborrar preguntes i opcions, importar enquestes des de JSON.
- Classes provades: CtrlEnquesta a traves de les invocacions de CtrlDomini;
  Pregunta, Opcio, Enquesta (estructura d'objectes) i validacions.

Altres elements integrats a la prova:
-------------------------------------
- Reutilitzacio de CtrlDomini i CtrlPersistencia per emmagatzematge i
  validacions.
- Parts del codi de Pregunta/Opcio s'executen i s'integren per comprovar
  interoperabilitat.

Fitxers de dades necessaris:
----------------------------
- Exemple d'enquesta JSON: exemple_enquesta_clustering.json (ubicat a
  ENTREGA/DOCS/).
- El fitxer conte la descripcio estructurada de l'enquesta (id, titol,
  preguntes, opcions). El test d'import nomes llegeix i descarta si el
  format es invalid.

================================================================================
VALORS ESTUDIATS
================================================================================

- Casos valids: crear enquesta amb id no existent, modificar titol d'enquesta,
  modificar descripcio d'enquesta, esborrar enquesta, afegir/modificar/esborrar
  preguntes de tots els tipus amb opcions correctes i importar enquesta.
- Casos invalids: intentar afegir enquestes duplicades, modificar/esborrar
  enquestes no existents, afegir preguntes duplicades, afegir opcions a
  preguntes numeriques, valors no numerics on s'esperen numeros.
- Estrategia: caixa blanca per validar rutes critiques (existencia d'IDs,
  rangs numerics) i caixa negra per provar entrades mal formades (strings
  buits, ordres no numerics).

================================================================================
EFECTES ESTUDIATS
================================================================================

- Comprovacio de la interaccio entre el driver i el model: llistats d'enquestes,
  visualitzacio de preguntes i opcions, missatges d'error informatius.
- Validacions en pantalla i reintents (p.ex. sol·licitar de nou un numero si
  l'entrada no es valida).

================================================================================
OPERATIVA (US RAPID)
================================================================================

Script d'execucio:
  Linux/Mac: ENTREGA/EXE/CtrlEnquesta/run_tests.sh
  Windows: ENTREGA\EXE\CtrlEnquesta\run_tests.bat

Execucio en Linux/Mac:
  cd ENTREGA/EXE/CtrlEnquesta
  chmod +x run_tests.sh
  ./run_tests.sh

Execucio en Windows:
  cd ENTREGA\EXE\CtrlEnquesta
  run_tests.bat

El script crida la task Gradle runCtrlEnquestaDriver des de ENTREGA/FONTS i
envia una sequencia d'inputs preparada. El fitxer PROVA.txt conte una execucio
d'exemple amb sortida capturada.

Si desitges executar el driver individualment:
  cd ENTREGA/FONTS
  ./gradlew runCtrlEnquestaDriver

================================================================================
NOTES
================================================================================

- Per provar la importacio, assegura't que exemple_enquesta_clustering.json
  esta disponible en la ruta indicada (o canvia la ruta en el script a
  ENTREGA/DOCS/exemple_enquesta_clustering.json).
- Pots executar el driver en mode interactiu amb ./gradlew runCtrlEnquestaDriver
  i fer proves manuals.
- El driver ofereix menu interactiu complet.
- Suporta tots els tipus de preguntes del sistema.
- Validacio integrada per evitar dades inconsistents.
- Permet proves amb enquestes mock preconfigurades.
