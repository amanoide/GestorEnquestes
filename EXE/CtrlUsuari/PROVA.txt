DOCUMENTACIÓ DE PROVA - CtrlUsuariDriver
=========================================

OBJECTE DE LA PROVA
-------------------
Prova del controlador d'usuaris i gestió de sessions.

Casos d'ús provats:
- Registrar nous usuaris
- Fer login
- Fer logout
- Gestionar enquestes creades per usuari
- Consultar respostes d'usuari

Classes provades:
- CtrlUsuari: lògica de gestió d'usuaris
- Usuari: classe de domini

ELEMENTS INTEGRATS
------------------
Classes reutilitzades:
- Enquesta: enquestes creades per l'usuari
- Resposta: respostes de l'usuari
- CtrlPersistencia: guardar/carregar usuaris

FITXERS DE DADES NECESSARIS
----------------------------
Opcionals:
- usuaris.json: usuaris guardats

VALORS ESTUDIATS (Caixa Negra)
-------------------------------
1. Usernames vàlids:
   - Alfanumèrics: "user1", "admin", "test_user"
   - Mínim 3 caràcters
   - Case sensitive: "User" ≠ "user"

2. Passwords:
   - Qualsevol cadena no buida
   - Mínim 4 caràcters
   - Proves: "1234", "password", "P@ssw0rd!"

3. Casos d'error:
   - Username duplicat (error esperat)
   - Login amb credencials incorrectes
   - Password buida (error esperat)
   - Username buit (error esperat)

4. Sessions:
   - Un sol usuari actiu alhora
   - Canvi d'usuari (logout + login)
   - Operacions sense login (error esperat)

EFECTES ESTUDIATS
-----------------
- Autenticació d'usuaris
- Gestió de sessió activa
- Visualització de perfil d'usuari
- Llista d'enquestes pròpies

OPERATIVA
---------
Execució:
```
cd FONTS
gradlew.bat runCtrlUsuariDriver
```

Opcions del menú:
1. Registrar usuari nou
2. Fer login
3. Fer logout
4. Consultar usuari actual
5. Llistar enquestes pròpies
0. Sortir

Flux típic:
1. Registrar usuari ("user1", "pass123")
2. Fer login amb "user1"/"pass123"
3. Consultar informació
4. Logout
