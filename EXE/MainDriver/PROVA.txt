DOCUMENTACIÓ DE PROVA - MainDriver
===================================

OBJECTE DE LA PROVA
-------------------
Driver principal integrat que prova el sistema complet de gestió d'enquestes.

Casos d'ús provats:
- Gestió completa d'usuaris (registre, login, logout)
- Creació i gestió d'enquestes
- Afegir, modificar i eliminar preguntes
- Responder enquestes
- Consultar estadístiques i resultats
- Persistència de dades (guardar/carregar)

Classes i controladors integrats:
- CtrlDomini (controlador façana principal)
- CtrlUsuari (gestió d'usuaris)
- CtrlEnquesta (gestió d'enquestes)
- CtrlPregunta (gestió de preguntes)
- CtrlResposta (gestió de respostes)
- CtrlPersistencia (guardar/carregar dades)

ELEMENTS INTEGRATS
------------------
Classes de domini reutilitzades i ja provades:
- Usuari: creació, autenticació, gestió d'enquestes pròpies
- Enquesta: estructura, preguntes associades, participants
- Pregunta: tipus (text lliure, numèrica, qualitativa), validacions
- Resposta: vinculació usuari-pregunta, modificació
- Opcio: opcions per preguntes qualitatives

Controladors especialitzats:
- Tots els controladors específics ja provats individualment
- Integració amb CtrlDomini com a punt d'accés únic

FITXERS DE DADES NECESSARIS
----------------------------
No requereix fitxers de dades previs.
El driver pot generar i guardar:
- enquestes.json: Enquestes creades (classe Enquesta)
- usuaris.json: Usuaris registrats (classe Usuari)
- respostes.json: Respostes dels usuaris (classe Resposta)

VALORS ESTUDIATS (Caixa Negra)
-------------------------------
Conjunts de dades de comportament homogeni:

1. Usuaris vàlids:
   - Username: cadenes alfanumèriques (mínim 3 caràcters)
   - Password: cadenes no buides
   - Proves: "user1"/"pass123", "admin"/"admin123"

2. Enquestes:
   - IDs únics: "E1", "E2", "ENQ001"
   - Títols: cadenes no buides
   - Descripcions: qualsevol text o null

3. Preguntes:
   - Text lliure: sense restriccions de resposta
   - Numèriques: valors dins rang [min, max]
   - Qualitatives: opcions predefinides amb/sense ordre

4. Casos límit:
   - Enquestes buides (sense preguntes)
   - Usuaris sense enquestes creades
   - Respostes null o buides
   - Múltiples usuaris contestant la mateixa enquesta

EFECTES ESTUDIATS
-----------------
Funcionalitats d'interacció provades:
- Menús interactius amb selecció numèrica
- Navegació entre diferents opcions
- Visualització de llistes (enquestes, preguntes, respostes)
- Missatges d'error descriptius
- Confirmacions abans d'operacions crítiques (eliminar)
- Vista de resultats i estadístiques

OPERATIVA
---------
Compilació i execució:
```
cd FONTS
gradlew.bat runMainDriver
```

Flux d'ús típic:
1. Registrar un usuari nou
2. Fer login amb l'usuari creat
3. Crear una enquesta nova
4. Afegir preguntes a l'enquesta
5. (Opcional) Logout i login amb altre usuari
6. Respondre l'enquesta
7. Consultar les respostes i estadístiques
8. Guardar les dades (persistència)
9. Sortir

Menú principal:
- Opció 1: Gestió d'usuaris
- Opció 2: Gestió d'enquestes
- Opció 3: Respondre enquestes
- Opció 4: Consultar resultats
- Opció 5: Persistència
- Opció 0: Sortir

Notes:
- Totes les operacions retornen missatges de confirmació
- Els errors es mostren clarament amb explicacions
- Les dades es mantenen en memòria durant l'execució
- Es pot guardar l'estat en qualsevol moment
